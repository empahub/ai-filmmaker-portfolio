How I work

Current pipeline

  2. 1

    Script

    Written with AI using my own prompts and skills, tuned to the visual style.

  3. 2

    Voice

    Full narration in ElevenLabs, directed with audio tags.

  4. 3

    Timing

    Transcribed to word-level timestamps, so every cut and effect lands on the exact word.

  5. 4

    Visuals

    Copyright-safe sourced images plus custom images and cutouts made in NanoBanana.

  6. 5

    Animation

    Built in code with Remotion (React) via Claude Code, rendered in 1–1.5 minute parts.

  7. 6

    Sound

    Music and SFX placed in code on the same timestamps, with the music automatically lowered under the voice and balanced loudness.

The speed comes from the setup. Each project folder has its own rule files (CLAUDE.md, PATTERNS.md, CONTINUITY.md) that define the style, how images are made, how scenes are split, and what's already done. A new script and voice file go in, and production starts immediately, looking the same in every session. Anything I do more than twice becomes a rule or a reusable step.

How I'd apply it to micro-dramas

  2. 1

    Style first

    Analyze reference videos, then turn the look, pacing, and lighting into written rules.

  3. 2

    Reference assets

    Character sheets for every recurring character (front, back, side, face close-up) and reference images for locations, built from approved assets.

  4. 3

    Generation

    Key frames built from the reference sheets, then animated with image-to-video, so every shot starts from an approved look.

  5. 4

    Dialogue

    Audio-first. Each character gets a fixed ElevenLabs voice, and the video model lip-syncs to that audio, so the same character sounds the same in every episode. When a native-audio take has the best performance, only the voice is swapped with speech-to-speech conversion, which keeps the timing and lip-sync.

  6. 5

    Edit

    9:16, music matched to mood, SFX on action and cuts, timed captions, and exports optimized for each platform.

  7. 6

    3D characters (when needed)

    An agentic pipeline: character concept, textured 3D model, then Blender retopology, UV mapping, and rigging, a production-readiness check, and stylized animation.

Cinematic / realistic productions

  • Script to shot list: storyboard with shot types, camera movement, and 9:16 framing before anything is generated.
  • Photoreal character sheets with fixed wardrobe, hair, and lighting.
  • A continuity file per series tracking wardrobe, props, locations, and time of day.
  • A consistent color grade and sound design across the series.

Preparation is more than half the work. A strong setup is what makes daily episodes fast and keeps characters from changing faces between episodes.
